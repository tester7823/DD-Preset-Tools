# DD Preset Tools — Trinket Sets, Party Lineups & Auto Buy (Darkest Dungeon 1)

Source code of the **DD Preset Tools** mod for **Darkest Dungeon** (Steam, 64-bit).
Players: get the mod from the Steam Workshop — it already contains the DLL and the installer.

| Tool | Where | What it does |
|---|---|---|
| **Trinket Sets** | Trinket bag (town) | Save up to 10 two-trinket sets, equip them from the hero screen in one click. Class-exclusive trinkets are respected (mod classes too). Duplicates are blocked. |
| **Party Lineups** | Estate Map (Caretaker button) | Save up to 10 four-hero lineups and load them into the party. Drag to swap, left-click to remove, right-click to open the hero screen. |
| **Auto Buy** | Provision screen | Buys the list in `autobuy.txt` in one go, stopping when gold runs out. |

## Install (players)

1. Subscribe to the mod on the Steam Workshop.
2. Close the game and run `dd_preset_tools\install\install.bat` in the mod folder (once).
   It renames `_windows\win64\SDL2.dll` to `SDL2_orig.dll` and puts the small loader `SDL2.dll` in its place.
3. Enable the mod in the in-game mod list (blue hammer).

Run `install.bat` again after a game update or *Verify integrity of game files*. `uninstall.bat` restores the original `SDL2.dll`.

## macOS (BETA)

The Workshop folder also contains `mac_only/` (macOS x86_64 build, runs natively on Intel Macs and through Rosetta 2 on Apple Silicon). **Not tested on a real Mac yet.**

1. Quit the game. In Terminal run `sh <mod folder>/mac_only/install_mac.sh` (drag the file into the Terminal window).
   It copies `Darkest.app/Contents/Frameworks/SDL2.framework/Versions/A/SDL2` to `SDL2_orig` and puts the loader `SDL2` in its place.
2. Enable the mod in the in-game mod list. `uninstall_mac.sh` restores the original.
3. Problem report: last line of `DarkestDungeon/_osx/trinket_preset.log` (`DDPT-REPORT …`).

Mac sources: `src/mac/` (`loader_mac.cpp` = SDL2 proxy that re-exports `SDL2_orig`, `game_mac.cpp` = game access for macOS; functions and data are found by symbol name at start-up, `hook.cpp` = small inline hook, `windows.h`/`win_shim.cpp` = the few Win32 calls the shared code uses). Build: `MACOS_SDK=/path/to/MacOSX12.3.sdk ./build_mac.sh` (clang + lld, works on Linux).

## How it works

- `src/loader.cpp` → **SDL2.dll** (loader). Forwards every SDL call to `SDL2_orig.dll`. On start it looks for `dd_preset_tools\dd_preset_tools.dll` inside `mods\*` or `workshop\content\262060\*` and loads it. Without it, the loader does nothing.
- everything else in `src/` → **dd_preset_tools.dll**. Draws the UI with Dear ImGui and calls the game's own functions (equip, party slots, store purchase). Features stay hidden unless the mod is enabled in the in-game mod list.
- **Game updates are detected automatically.** On start the DLL scans `Darkest.exe` for the byte patterns in `src/sigs.inc` (`src/sigscan.cpp`) and reads function/data addresses, the trinket-library entry size and the hero struct offsets from the game's own code. Each pattern must match exactly once; if a required one is missing, game features turn off instead of guessing (the log line `[자동 인식]` lists what failed). The patterns are generated and checked by `tools/sigs/gen_sigs.py` (`DDPT_EXE=…/Darkest.exe python3 tools/sigs/gen_sigs.py`, needs `llvm-objdump`); current table: 2026-10-30 build (timestamp `0x6AE4C882`).
- macOS: functions/data come from the game's symbol table (demangled names); the trinket-library entry size and hero offsets are calibrated from live data.

## Repository layout

| Path | Contents |
|---|---|
| `src/` | Loader and mod DLL source (C++17) |
| `installer/` | `install`/`uninstall` scripts shipped in the mod folder (`installer/mac/` for macOS) |
| `mod/DD_Preset_Tools/` | Workshop folder data (project.xml, autobuy.txt, README). `localization/` is generated by `tools/build_loc.py`; game-art images are not included here. |
| `tools/` | `build_loc.py` (text → `.loc2` localization), `strings.py` (all UI text, 12 languages), `gen_proxy_def.py` (loader export table) |
| `fetch_deps.sh` | Downloads Dear ImGui 1.91.5, MinHook, SDL 2.30.9 headers and stb_image into `third_party/` (run automatically by `build.sh`) |

## Build

Requires [llvm-mingw](https://github.com/mstorsjo/llvm-mingw), git and Python 3 (Linux, macOS or WSL).

```sh
export LLVM_MINGW=/path/to/llvm-mingw
./build.sh            # → build/x64/SDL2.dll, build/x64/dd_preset_tools.dll
python3 tools/build_loc.py mod/DD_Preset_Tools   # regenerate localization
```

## Translations

All text lives in `tools/strings.py` (keys `ddpt_*`). Add or fix a language there, run `build_loc.py`, and open a pull request.

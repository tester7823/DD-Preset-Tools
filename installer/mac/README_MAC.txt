DD Preset Tools - macOS (BETA)
==============================
This folder is only for Mac. Windows players can ignore it.
Not tested on a real Mac yet - please report problems!

Install
  1. Quit the game.
  2. Open Terminal (Applications > Utilities > Terminal).
  3. Type  sh  and a space, drag "install_mac.sh" from this folder into the Terminal window, press Enter.
  4. Start the game and turn on "DD Preset Tools" in the mod list.
  (After a game update or "Verify integrity", run install_mac.sh again.)

Uninstall
  Same as above with "uninstall_mac.sh" (or Steam > Verify integrity of game files).

Reporting a problem
  Post the LAST line of this file in the Workshop comments (starts with DDPT-REPORT):
    .../steamapps/common/DarkestDungeon/_osx/trinket_preset.log
  If that file does not exist, tell us and post the contents of
    .../steamapps/common/DarkestDungeon/_osx/dd_preset_loader.log

Not available on Mac yet: opening the hero info window from a party preset.

DD Preset Tools - 맥 (베타)
이 폴더는 맥 전용입니다. 윈도우 사용자는 신경 쓰지 않아도 됩니다.
아직 실제 맥에서 테스트하지 못했습니다. 문제가 있으면 알려 주세요!

설치
  1. 게임을 끕니다.
  2. 터미널을 엽니다 (응용 프로그램 > 유틸리티 > 터미널).
  3. sh 와 띄어쓰기를 입력하고, 이 폴더의 "install_mac.sh" 를 터미널 창에 끌어다 놓은 뒤 Enter.
  4. 게임을 켜고 모드 목록에서 "DD Preset Tools" 를 켭니다.
  (게임 업데이트나 "파일 무결성 확인" 뒤에는 install_mac.sh 를 다시 실행하세요.)

제거
  위와 같은 방법으로 "uninstall_mac.sh" 실행 (또는 Steam > 게임 파일 무결성 확인).

문제 신고
  아래 파일의 마지막 줄(DDPT-REPORT 로 시작)을 창작마당 댓글로 남겨 주세요:
    .../steamapps/common/DarkestDungeon/_osx/trinket_preset.log
  이 파일이 없으면 그렇다고 알려 주시고 아래 파일 내용을 남겨 주세요:
    .../steamapps/common/DarkestDungeon/_osx/dd_preset_loader.log

맥판에서 아직 안 되는 것: 영웅 프리셋에서 영웅 정보창 열기.

# ---------------------------------------------------------------
#  Auto Buy list  (the [Auto Buy] button on the Provision screen)
#  자동 구매 목록  (원정 준비 화면의 [자동 구매] 버튼)
# ---------------------------------------------------------------
#  Items are bought from top to bottom.
#  Buying stops as soon as you run out of gold.
#
#  Format:   item   amount
#    - "all" buys everything the store has.
#    - Lines starting with # are ignored.
#
#  Item names:
#    food  torch  shovel  key  antivenom  bandage  herbs
#    holy water  laudanum  firewood  dog treats
#    (Korean names also work: 식량 횃불 삽 열쇠 해독제 붕대 약초 성수 아편 장작 개 간식)
#    (game IDs also work: provision, skeleton_key, medicinal_herbs ...)
#    (items from other mods:  type:id  e.g.  supply:my_item  2)
#
#  Per-dungeon lists:
#    The mod checks which expedition you picked and uses the matching
#    [dungeon length] list below. If there is no matching list
#    (Darkest Dungeon, Farmstead, Courtyard, mod dungeons ...),
#    the [default] list is used.
#      dungeon: ruins  warrens  weald  cove   (or 폐허 사육장 삼림 해안)
#               other dungeons: their game ID, e.g. [farmstead short]
#      length : short  medium  long           (or 짧음 중간 긺)
#    던전별 목록: 고른 원정에 맞는 [던전 길이] 목록을 사용하고,
#    맞는 목록이 없으면 (가장 어두운 던전, 농장, 안뜰, 모드 던전 등) [default] 목록을 사용합니다.
#
#  Items that cost shards are never bought.
#  Changes apply immediately after saving this file.
#  Per-dungeon amounts: based on the guide at
#  https://gall.dcinside.com/mgallery/board/view/?id=darkest&no=2259
# ---------------------------------------------------------------
